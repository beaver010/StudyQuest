# ⚡ StudyQuest

Лёгкое статическое веб-приложение (HTML + CSS + JS, без сервера и зависимостей) для подростков: добавляй учебные задачи, выполняй их и зарабатывай очки опыта.

## Запуск

Просто открой файл **`index.html`** двойным кликом в любом браузере. Ничего устанавливать не нужно — приложение полностью работает в браузере.

## Возможности

- ➕ **Добавление задач** — поле ввода + выбор предмета.
- 🎚️ **Выбор очков** — три плитки сложности: легко = 20 XP, средне = 40 XP, сложно = 70 XP.
- 🧮 **Карточка счёта** — крупное число всех набранных очков, уровень, серия и полоска прогресса до следующего уровня.
- 📈 **Уровни** — каждый новый уровень требует на 100 XP больше предыдущего. При переходе появляется поздравление.
- 🔥 **Серия (streak)** — каждый день с выполненными задачами увеличивает серию; пропустил день — серия сбрасывается.
- 🔁 **Снятие отметки** — XP честно возвращаются, если снять галочку с выполненной задачи.
- 🧹 **Фильтры** — «Все», «В работе», «Выполнено».
- 🎭 **Проработанные состояния** — пустой список с анимацией, наведение на задачи и кнопки, свечение поля в фокусе, приглушённая выполненная задача с зачёркиванием.
- 💾 **Автосохранение** — прогресс хранится в `localStorage` браузера и не исчезает после перезагрузки страницы.
- 🎨 **Тёмная современная тема** — стеклянные карточки, неоновые градиенты, адаптивность под ноутбук (две колонки) и телефон (всё в одну колонку).

## Как сбросить прогресс

Открой консоль браузера (F12 → Console) и выполни:

```js
localStorage.clear();
location.reload();
```

## Возможные идеи для развития

- Звуковые/световые эффекты при выполнении задачи.
- Ачивки (например, «10 задач за день»).
- График активности по дням недели.
- Экспорт/импорт прогресса в файл.
